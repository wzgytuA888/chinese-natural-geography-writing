# 方法与参数：写作口径

本文件用于准确解释用户已采用的方法，不是选择模型的通用处方。原版未经同口径验证的频次、主流排名和普适精度阈值不再使用。自动提及篇数仅见 corpus-statistics.json，受抽取和匹配条件影响，不能等同于方法实际采用篇数。

| 方法/输出 | 应报告 | 解释边界 |
|---|---|---|
| InVEST/ARIES 服务估算 | 模块、定义、单位、输入与本地参数、验证 | 不同定义与碳库先统一再比较；估算不是实测 |
| PLUS/FLUS 土地模拟 | 情景约束、训练/验证期、数量和空间配置误差 | 历史精度不证明未来情景必然实现 |
| SWAT/过程模型 | 率定/验证期、流量尺度、多个精度维度 | 出口流量验证不能替代像元服务量验证 |
| Budyko/弹性归因 | 框架、假设、分母、分期与残差 | 份额受模型假设影响；可有抵消项 |
| 地理探测器 | 分层方法、q、检验与交互判据 | q 是分异解释力；交互增强不是因果协同 |
| 随机森林/XGBoost | 验证设计、重要性定义、稳定性 | 重要性不自动提供方向与因果 |
| GWR/空间计量 | 权重、带宽、诊断、局地/邻近关系 | 空间回归关系是否因果取决于识别设计 |
| 结构方程 | 路径假设、识别、拟合、直接/间接系数 | 拟合不证明唯一机制 |
| 相关/袋状图/约束线 | 样本维度、尺度、方向、统计量 | 不同方法不同含义；不显著关系单列 |
| 耦合协调/障碍度 | 子系统、标准化、权重、等级来源 | 高耦合不等于高协调；障碍不是决定原因 |
| MSPA/阻力面/电路理论 | 阈值、阻力依据、节点与扰动 | 规划推断不等于实际恢复效果 |

## 参数与精度

参数至少追溯到“名称/定义—值或范围—单位—来源—本地调整—敏感性”。引用别区参数时说明适用理由；不从知识卡片自动迁移碳密度、植被系数、阻力值或情景成本。

Kappa、总体精度、NSE、R²、PBIAS、RMSE 衡量的维度不同。用当前模型、变量、时间尺度和评价目的的既定标准解释；“Kappa≥0.75”“NSE>0.5”不作为本 skill 的普适门槛。用户未提供标准时先报告指标，不自行下“精度完全满足要求”的结论。

所有参数来源、阈值出处和统计显著性须核验；自动文本统计不能提供这种证据。若输出 Word，公式使用公式编辑器可编辑对象。
