# 发现组织模式：不预设结果方向

以下用于寻找当前数据值得表达的对照，不是科学结论的默认答案。建设用地、林地、气候和服务变化的方向必须由用户结果决定；本 skill 不预设生态保护情景最优、经济情景最差或某类服务一定协同。

| 当前材料 | 优先检查的对照 | 可写判断的条件 |
|---|---|---|
| 地类转换与服务量 | 转入/转出、净变化/总转移、总量/强度 | 同期同尺度，分母明确 |
| 多项服务关系 | 指标方向、相关维度、显著/不显著、尺度反转 | 统计方法和样本定义已知 |
| 供给和需求 | 两者变化幅度、比值、盈余/赤字 | 同单位、同口径，供需公式明确 |
| 服务流 | 静态匹配/流动后匹配、潜在/实际 | 有路径或流量依据，不只位置相邻 |
| 多情景 | 同基准的分目标收益和代价 | 年份、输入、约束可比 |
| 协调与障碍 | 两系统水平、协调等级、滞后类型 | 权重、等级与类型判据明确 |
| 归因或重要性 | 输出含义、排序、份额/方向 | 不把不同模型量度统一为真实贡献 |
| 趋势与突变 | 全期/阶段、显著/不显著、检验冲突 | 足够序列及已有检验 |
| 多模型与数据源 | 共识维度、方向冲突、定义/参数差异 | 同一评价对象，验证边界明确 |
| 安全格局/网络 | 源地、廊道、脆弱单元、扰动敏感性 | 阈值、阻力与情景依据清楚 |

段落组织可用“中心发现—代表证据—对照/例外—范围”；讨论再加入中间过程和可比文献。只有空间统计时不用时间增减骨架；只有两端点时不用波动或阶段转折骨架。

与常见认识相反的结果先核对数据口径，再如实报告；差异可成为发现，不要为贴近期刊范文而改动方向。原创演练见 [worked-analysis-examples](../references/worked-analysis-examples.md)。
