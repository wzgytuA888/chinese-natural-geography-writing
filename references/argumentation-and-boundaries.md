# 论证规则与条件边界

适用于讨论、结果分析、引言问题构建和结论。期刊中的措辞并非自动正确；迁移结构时仍需检查指标定义、识别设计和推论成立条件。

## 1. 让观察与解释之间有明确的桥

| 观察 | 论证下一步 | 需要的证据 |
|---|---|---|
| A 与 B 同步变化 | 候选共同因素，或直接路径 | 控制变量、过程观测、识别设计 |
| 总体与局部方向不同 | 检查空间聚合、样本构成、情景 | 同变量在可比尺度的结果 |
| 模型间结果差异 | 先检验定义与输入，再解释结构 | 同对象同单位、参数与验证信息 |
| 综合指数上升但单项下降 | 分解权重和服务间代价 | 指标方向、标准化与权重 |
| 供给增加但供需比下降 | 检查需求增速与比值定义 | 同时期、同口径的供给和需求 |
| 重要性高但方向未知 | 只写预测重要性，提出待检验路径 | 效应解释方法或过程证据 |

“理论上合理”只能支持候选解释，不能补齐本研究没有测量的中间过程。明示某路径是本文检验、模型结构假定，还是文献启发的推测。

## 2. 五组容易混淆的生态系统服务判断

1. **产水与水源涵养**：先按本研究公式定义。保水、入渗、削峰、补枯、净输出不是同一个量；不同“涵养量”定义下数值不能直接评判方法优劣。参照 p047、p059。
2. **潜在供给、需求与实际使用**：静态盈余不等于服务已输送到受益区。服务流须说明载体、路径、传递限制与损耗；没有流量或路径数据时只写供需匹配。参照 p011、p050、p088。
3. **权衡/协同与增减**：空间正相关可对应“高值一起高、低值一起低”，不能推出两项服务随时间都增加。负相关可作为统计权衡表征，但不直接证明竞争机制。参照 p042、p079、p083。
4. **总量与强度**：地类总服务贡献大可能源于面积大，不能推出该地类单位面积效率高。必须注明比较维度。参照 p054、p074。
5. **综合改善与单项改善**：某情景综合指数较高，不保证所有服务改善；主张“最优”前须说明目标、权重、成本和可行性。参照 p031、p074。

## 3. 比较文献，先建立可比性

讨论不要只写“一致/不同”。至少核对：服务/水文量定义、研究区背景、时段、粒度和范围、数据与模型、情景/控制条件。先报告一致的维度，再定位差异；可能的原因按已有证据排列，而非为解释冲突临时增加新变量。

p006 的方法比较把空间方向与数值差异分开，并将差异接到参数、林分与尺度信息；p059 则进一步区分相同评价内容的模型差异和不同评价内容的概念差异。可迁移的是这一比较顺序，不是原文中的某项估算值。

## 4. 引言中的缺口要能导出问题

“研究较少”之后须说明缺少什么使哪项判断无法完成，然后把缺口转为可检验问题。例如，静态供需匹配无法确定跨区服务到达受益者的程度，因此需要识别传递路径与实际服务量。若本研究只做静态评价，就不能声称填补服务流研究空白。

方法复杂不构成贡献。贡献可在可比数据、概念澄清、尺度反转、不同过程的区分或不确定性传播上；必须对应本研究实际完成的证据。

## 5. 情景与归因的限定

- 历史描述、情景比较和现实政策效应分列。情景间差异只在给定气候、需求、参数与土地约束下成立。
- 固定气候时变化土地利用可估计模型内土地利用差异；不能外推为真实未来全部变化。
- q、特征重要性、偏相关、路径系数、Budyko 分解份额的含义各异。表述变量方向、贡献份额和因果效应前，确认该输出确实提供它们。
- 拟合精度高不能证明机制唯一；出口径流验证不自动支持每个像元的涵养精度；情景模拟的历史验证不证明未来情景会发生。
- 有拟合曲线不自动有“阈值”。需交代识别方法、阈值值域及稳定性；否则写非线性或候选转折。

## 6. 管理意义回扣诊断

用“区域/类型 → 证据中的限制或代价 → 对应管理方向 → 适用条件”组织建议。空间模型划定的源地/廊道可支持优先核查区域，不能直接宣称完成真实生态修复。未核验政策时，可提出基于结果的管理方向，避免补造具体政策名称或强制标准。

## 7. 让局限改变结论的边界

弱写法：受数据限制，未来需加强研究。

可用写法：本研究采用固定地类碳密度，因此情景间碳储量差异主要反映地类转换；林龄和管理变化引起的碳密度调整尚未计入，应在后续模拟中引入动态参数检验该排序是否稳定。

只在研究确实采用上述设定时使用这条解释。局限必须关联可能受影响的结论和可执行的补充检验。
