# 句法、搭配与段落衔接

本文件把多篇论文反复出现的表达功能转为可操作规则。下面的示例均为原创演示。证据索引见 [distillation-evidence.md](distillation-evidence.md)。句长统计用于观察节奏，不用于强制凑字。

## 1. 句子的主干必须能单独成立

| 功能 | 句法动作 | 原创例句 |
|---|---|---|
| 限定后判断 | 将时间/尺度置于主语前，再给一个主要谓语 | 在县域尺度上，服务供需比的区域差异大于其时点差异。 |
| 总体与例外 | 用“总体……，但……”保留反向单元 | 两期碳储量总体增加，但北部单元的估算值下降。 |
| 分解后比较 | “其中”承接上句同一集合，“而”对照同类量 | 三类地表覆盖的面积变化方向不同，其中林地增加，而耕地减少。 |
| 分维度报告 | 先声明维度，再报告该维度的结果 | 从单位面积强度看，山区高于平原；按总量比较，两区排序相反。 |
| 条件化机制 | “可能通过 A 改变 B，进而影响 C”并给条件 | 在水分受限地区，植被扩张可能通过增加蒸散耗水改变可利用水量。 |
| 尺度反转 | 保持变量对不变，只改变尺度条件 | 两项服务在县域尺度上呈正相关，而在格网尺度上呈负相关。 |

一个句子出现两个以上“通过”、多个“从而/进而”，或修饰语离主语过远时，拆成判断句与过程句。分号用于同一主题下的平行比较；不同论点应分句或分段。

## 2. 主语连续，避免指代漂移

- “这一变化”只能回指已经明确的一项变化；若上句同时出现服务量和供需比，应重写为“供需比的下降”。
- “其中”后面的对象必须属于前述集合；不能从三类服务突然跳到某行政区。
- “分别”须与两侧对象一一对应；多组年份、区域和指标并列时，优先采用逐组短句或表格。
- “其”前有两个可能先行词时直接重复术语；避免为减少重复而牺牲可读性。
- 数值跟随对应指标；不要把多个单位、多个分母放在句尾让读者自行匹配。

## 3. 连接词按逻辑关系选择

| 词语 | 所需关系 | 不合适的情况 |
|---|---|---|
| 而、相比之下 | 同一维度上对照 | 比較基准或单位不同 |
| 但、然而 | 前述概括的例外/预期冲突 | 两个互不相关的结果 |
| 同时、此外 | 并列信息/新增侧面 | 充当未检验的因果桥 |
| 进一步、在此基础上 | 新分析建立在已有结果之上 | 只更换指标而无递进关系 |
| 因此、由此 | 上文足以推出下文判断 | 从相关直接推出现实因果 |
| 由于、进而 | 具备过程或识别依据的解释 | 因句式“像期刊”就补原因 |

语料中“但”比“但是”多，不构成禁用“但是”的理由。“值得注意的是”适合会改变主结论的例外；普通报数无须使用。不要为避免重复，轮换一整串连接词。

## 4. 名词与动词搭配

| 对象/输出 | 合适搭配 | 需要额外证据的升级 |
|---|---|---|
| 面积、服务总量、模型估算值 | 增加、减少、较期初变化 | 改善/恶化须有评价方向 |
| 空间图/分区均值 | 分布于、主要集中于、呈空间差异 | “空间集聚显著”须空间检验 |
| 相关系数 | 呈正/负相关、相关程度 | 促进、抑制、互相驱动 |
| q 值 | 对空间分异的解释力、解释力较高 | 真实变化贡献率 |
| 随机森林重要性 | 预测重要性、关键预测特征 | 正向作用、因果主导 |
| 情景估算 | 给定假设下、模拟结果显示 | 必将、已经实现 |
| 不确定性 | 来源于、可能改变某比较、限制外推 | 一句“仍有局限”了事 |
| 服务簇 | 以某组标准化服务特征为主的类型 | 客观固有类型、普遍最优组合 |

“表明”是证据报告动词，“呈现”是现象描述动词；它们不是可以自由升降的因果强度等级。“主导”必须写明主导什么：面积构成、统计解释还是过程机制。

## 5. 提升分析密度，减少术语密度

弱句：研究区具有复杂的空间异质性和动态演变特征。

若有相应数据，可改为：研究区服务强度的南北差异保持稳定，但低值分区在第二期扩大。

改进来自明确维度、方向和比较，而非把“变化”替换成“演变”。只给两期数据时，不把“后一期较前一期高”改成“持续上升”。不能将“差异”自动改为“显著分异”。

## 6. 数字、标点与英文术语

- 同一稿内统一时间区间、单位、图表引注和 P 值写法；投稿时以目标期刊规范为准，不把语料习惯声称为官方规范。
- 图号、统计量符号、公式编号沿用用户提供内容；未提供图号时不要虚构“图 3”。
- 模型名首次出现可给全称/缩写，但不得凭印象扩写不熟悉的名称。
- 连字符、区间线与负号用途不同；数值范围保持清楚，负值不能因格式统一而丢失。
- Word 输出中的公式使用公式编辑器可编辑对象（OMML），不以公式截图替代。
