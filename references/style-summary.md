# 写作风格总览

两刊相关论文中可迁移的共同特征是：对象明确、比较维度清楚、数值支撑判断、总体与例外并存，机制讨论与尺度条件相联系。不同论文的篇章组织有差异，不能把某一生态系统服务研究链当作所有文章的固定顺序。

风格提升首先来自信息和逻辑：用指标方向代替“越来越好”，用可比数值代替“影响很大”，用有条件的过程解释代替单一因果口号。名词化和专业术语只在概念准确时使用，不把所有普通词替换为复杂词。

句法见 [grammar-and-collocations.md](grammar-and-collocations.md)，数据写作见 [data-to-prose.md](data-to-prose.md)，机制与意义边界见 [argumentation-and-boundaries.md](argumentation-and-boundaries.md)。

本批统计口径和提取局限见 [corpus-findings.md](corpus-findings.md)。句长与词频是描述性结果，不是官方投稿规范或文风质量评分。语料中的因果强词、模糊显著性或混合段落不应未经检查照搬。
