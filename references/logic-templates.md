# 逻辑结构模板

按研究问题和已有信息选用。以下顺序是可选组织示意，不要求所有论文包含每个模块；不存在的关系、驱动、精度阈值、分区占比和情景不得为凑齐模板而补造。更具体的条件见 [argumentation-and-boundaries.md](argumentation-and-boundaries.md)。

## 1. 实证型论文

### 引言

现实或理论背景 → 概念与研究进展 → 不足与空白 → 科学问题 → 研究设计与贡献。

典型收束：

> 既有研究已从 A、B 和 C 三个方面形成较为系统的认识。然而，关于 D 的识别仍主要基于……，对 E 过程及其尺度差异关注不足，因而难以解释……。基于此，本文以……为研究对象，采用……方法，重点回答以下问题：……。

### 方法

按“为什么选—如何算—如何检验—有什么边界”组织：研究区与分析单元；数据与预处理；指标或模型选择理由；计算过程；稳健性、精度或不确定性检验。

### 结果

推荐顺序：模型/数据可靠性 → 总体趋势 → 空间格局 → 类型或阶段差异 → 因素及阈值 → 稳健性与异质性。每段采用“判断—证据—比较”，不大篇幅解释原因。

### 讨论

关键发现 → 与已有研究比较 → 机制路径 → 尺度、区域、阶段、阈值或情景条件 → 理论或管理含义 → 局限与后续研究。

### 结论

按研究问题逐条回答。先写发现，再写条件；不引入新数据、新文献和未经讨论的新机制。

## 2. 综述与概念框架型论文

背景与概念争议 → 概念边界和分类 → 研究进展的主题化归纳 → 文献评述 → 多尺度或多主体框架 → 研究议程。

文献不足可从对象、尺度、时间、机制、方法和治理六个维度识别。不要只写“研究较少”，而要说明这种不足造成了什么解释困难。

## 3. 案例—过程—机制型论文

理论概念 → 分析框架 → 案例选择理由 → 时序分期 → 各阶段空间/制度变化 → 多维机制 → 理论回扣。

机制部分需说明主体拥有什么资源、采取何种实践、改变了何种空间关系、最终形成何种景观或治理结果。

## 4. 模型—情景—优化型论文

治理问题 → 现有方法瓶颈 → 系统模型 → 情景构建 → 多目标优化 → 精度/性能评价 → 决策规则。

方法创新应回答：原方法在哪个环节失效？新方法改变了哪个环节？这种改变在精度、效率、可解释性或决策可用性上产生了什么增益？

## 5. 科学问题与假设

科学问题提出未知关系；研究假设给出可检验的方向和机制。例如：

> 科学问题：不同气候情景下，水生态系统服务的时空响应是否具有一致性？

> 假设：降水变化主要通过改变地表—地下水补给过程影响供水服务，而温度升高可能通过增强蒸散和污染物反应过程改变水质净化服务，因此不同服务类型的响应方向和阈值并不一致。

## 6. 完整讨论链

> 本研究发现 X。该结果与 Y 类研究总体一致，但在 Z 区域/尺度上表现出不同特征。其原因可能在于 A 改变了 B 过程，进而作用于 C；同时，D 条件对该作用形成约束。由此表明，理解该现象需要同时考虑 E 的尺度差异和 F 的情景依赖性。该认识可为 G 提供依据，但由于 H 数据或模型限制，相关机制仍需结合 I 证据进一步验证。

## 7. 事件—阶段—异常型论文

总体长期变化 → 事件或突变识别 → 阶段边界交叉验证 → 事件内部类型 → 季节/区域差异 → 异常单元 → 大尺度背景与可能机制。

关键要求：先区分“趋势不显著、阶段停滞、方向反转和统计突变”，再讨论它们是否同步。异常区域不是附带结果，而是检验总体解释是否成立的关键证据。

## 8. 多源数据—串联模型型论文

单一数据瓶颈 → 多源互补理由 → 校正/率定 → 分辨率与尺度统一 → 上游模型验证 → 下游过程模拟 → 独立或聚合尺度验证 → 误差传递与适用边界。

若模型 A 的输出进入模型 B，必须先证明 A 在目标区域和尺度上达到可接受精度，再解释 B 的结果。不能用最终结果“看起来合理”反向替代上游验证。

## 9. 路径与空间关系型论文

理论分类 → 关系或路径假设 → 前提检验 → 模型拟合 → 总体结构 → 直接/间接或本地/邻近效应 → 异质性 → 机制解释。

结构方程适合回答变量如何沿路径传导；空间计量适合区分本地与邻近关联；社会网络适合描述关系数据的整体结构。三类结果不可混用为同一种“机制证据”。

## 10. 机器学习解释型论文

高维问题 → 传统方法限制 → 算法选择 → 训练与验证 → 重要性/解释值 → 稳定性与阶段变化 → 过程解释 → 可干预性判断。

重要性只能作为候选关键因素的识别依据。若需写方向、阈值或因果作用，应增加相应解释方法、统计设计或过程证据。

## 11. 土地利用变化—生态系统服务响应型论文

服务意义与政策背景 → 方法谱系与三类缺口（区域/方法/验证） → 研究设计 → 土地利用变化 → 各服务时空格局 → 服务与地类对应 → 关键地类与转移方向 → 机制与分区调控。

结果严格“先格局后归因”：总体格局 → 高/低值区 → 服务量排序 → 与地类变化的对应关系。服务量与地类转移写在同一句，使归因可直接回溯证据。

## 12. 权衡/协同与供需匹配型论文

关系研究空白（多综合少分类型、多静态少时空）→ 各服务格局 → 整体关系方向 → 关系强度的空间分异 → 单元归类（协同区/权衡区）→ 尺度效应 → 调控含义。

供需型则按“供给格局 → 需求格局 → 匹配类型 → 服务流路径”组织，用盈余/赤字、空间错位、流动前后对比表述。关系结论必须写“方向 + 强度 + 空间占比”。

## 13. 情景模拟与预测型论文

现实与政策背景（引具体规划文件）→ 单服务/静态/单模型的局限 → 情景设定理由与约束表 → 数量约束 + 空间模拟 + 服务评估的模型链 → 精度验证 → 历史演变与多情景预测 → 情景对比 → 相对最优情景与风险提示 → 分区差异化管控。

精度验证独立成段并置于结果之前；情景对比统一用“较……情景，……提升/下降……”。避免确定化措辞，用“预计将”“倾向于”。

## 14. 耦合协调型论文

政策背景 → 两系统内涵界定 → 双向作用（A→B 与 B→A）→ 空白：多单一系统、静态 → 指标体系 → 综合水平 → 耦合协调度 → 时空演化 → 滞后/受阻亚类与障碍度 → 分区分类治理。

协调度必须分级并叠加亚类判定方向；讨论须区分“高耦合”与“良性协调”，并给出协调影响力或障碍度证据。

## 15. 驱动分离与归因分解型论文

“因子清单丰富但未区分层级与贡献”的空白 → 归因方法依据（弹性、Budyko、探测器、相对重要性）→ 各因子贡献的百分比对举 → 多方法互证 → 中介过程 → 适用边界。

份额写为统计结果而非物理定律；讨论把高贡献因子与具体过程连起来，并说明遗漏变量的可能影响。

## 16. 趋势—突变—归因链型论文

领域重要性 → 并列两条方法路线各自局限 → “问题×尺度×方法”三重缺口 → 数据与模型 → 趋势检验（含显著性）→ 突变识别（多法交叉）→ 归因分解（气候 vs 人类/下垫面）→ 情景预估 → 不确定性小节。

先给统计量与阈值再下判断；多法识别不一致时如实报告冲突，不择优选取。

## 17. 概念辨析与理论框架型论文

缘起与概念史 → 并置不同视角定义 → 分歧根源（视角/尺度、存量/通量）→ 内涵—外延—测度界定 → 相近概念判据 → 研究框架 → 分层议程（内容/方法/尺度/政策）。

“研究较少”只是起点，须说明不足造成的具体解释困难；议程需含对象、路径与目的，避免“加强研究”式空洞表述。

## 18. 生态安全格局与网络型论文

服务/韧性作为源地依据 → 空白：格局与韧性脱节 → 源地识别 → 阻力面与廊道 → 网络结构 → 韧性/可达性与扰动响应 → 关键节点与修复分区 → 国土空间管控工具（三区三线、蓝绿网络）。

廊道与阻力面属规划性推断，须写明依据；韧性结论限定在给定阻力体系与情景下。
