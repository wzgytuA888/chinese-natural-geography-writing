# 逻辑结构模板

## 1. 实证型论文

### 引言

现实或理论背景 → 概念与研究进展 → 不足与空白 → 科学问题 → 研究设计与贡献。

典型收束：

> 既有研究已从 A、B 和 C 三个方面形成较为系统的认识。然而，关于 D 的识别仍主要基于……，对 E 过程及其尺度差异关注不足，因而难以解释……。基于此，本文以……为研究对象，采用……方法，重点回答以下问题：……。

### 方法

按“为什么选—如何算—如何检验—有什么边界”组织：研究区与分析单元；数据与预处理；指标或模型选择理由；计算过程；稳健性、精度或不确定性检验。

### 结果

推荐顺序：模型/数据可靠性 → 总体趋势 → 空间格局 → 类型或阶段差异 → 因素及阈值 → 稳健性与异质性。每段采用“判断—证据—比较”，不大篇幅解释原因。

### 讨论

关键发现 → 与已有研究比较 → 机制路径 → 尺度、区域、阶段、阈值或情景条件 → 理论或管理含义 → 局限与后续研究。

### 结论

按研究问题逐条回答。先写发现，再写条件；不引入新数据、新文献和未经讨论的新机制。

## 2. 综述与概念框架型论文

背景与概念争议 → 概念边界和分类 → 研究进展的主题化归纳 → 文献评述 → 多尺度或多主体框架 → 研究议程。

文献不足可从对象、尺度、时间、机制、方法和治理六个维度识别。不要只写“研究较少”，而要说明这种不足造成了什么解释困难。

## 3. 案例—过程—机制型论文

理论概念 → 分析框架 → 案例选择理由 → 时序分期 → 各阶段空间/制度变化 → 多维机制 → 理论回扣。

机制部分需说明主体拥有什么资源、采取何种实践、改变了何种空间关系、最终形成何种景观或治理结果。

## 4. 模型—情景—优化型论文

治理问题 → 现有方法瓶颈 → 系统模型 → 情景构建 → 多目标优化 → 精度/性能评价 → 决策规则。

方法创新应回答：原方法在哪个环节失效？新方法改变了哪个环节？这种改变在精度、效率、可解释性或决策可用性上产生了什么增益？

## 5. 科学问题与假设

科学问题提出未知关系；研究假设给出可检验的方向和机制。例如：

> 科学问题：不同气候情景下，水生态系统服务的时空响应是否具有一致性？

> 假设：降水变化主要通过改变地表—地下水补给过程影响供水服务，而温度升高可能通过增强蒸散和污染物反应过程改变水质净化服务，因此不同服务类型的响应方向和阈值并不一致。

## 6. 完整讨论链

> 本研究发现 X。该结果与 Y 类研究总体一致，但在 Z 区域/尺度上表现出不同特征。其原因可能在于 A 改变了 B 过程，进而作用于 C；同时，D 条件对该作用形成约束。由此表明，理解该现象需要同时考虑 E 的尺度差异和 F 的情景依赖性。该认识可为 G 提供依据，但由于 H 数据或模型限制，相关机制仍需结合 I 证据进一步验证。
