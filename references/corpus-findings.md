# 本批 100 篇语料统计：可复算口径

生成日期：2026-10-10。来源为用户提供的文献 ZIP；两刊各 50 篇，共 1,485 个 PDF 物理页。年份覆盖 2010—2026，具体构成见机器可读统计。

## 统计对象与处理

使用 8 个本地进程 worker，从每页文本块按栏顺序抽取；修复部分旧版 E-* 字体映射和 Yi 字符标点，做 NFKC 规范化。字体修复以 p006 第 1、4 页 OCR 对照建立映射，仅用于对应字体，不替换正常汉字。其余异常字符和数学式仍可能影响提取。

自动识别标题与章节，排除识别出的参考文献、图表标题和重复页边文本；保留至少 15 个汉字、去空白长度 20—400 字符、汉字比例不低于 45% 的句子。句界为中文句号、问号、叹号；分号不拆句。

本口径纳入 **10,921** 个句子，包含 **678,196** 个汉字。它是筛选后的可分析文本量，不是 PDF 全文总字数或全文阅读量。旧版“约 370 万字”等数据不能由本口径直接复现，本版以本次可复算结果为准。

原始 PDF 与抽取全文不进入仓库；[统计 JSON](../knowledge/corpus-statistics.json) 给出分组结果，[书目 JSON](../knowledge/corpus-bibliography.json) 给出文件散列、页数与提取状态。

## 可复算方法

在已安装 PyMuPDF 的环境中执行（路径自行替换，cache 必须位于仓库外）：

```powershell
python scripts/distill_corpus.py "论文.pdf.zip" --cache "D:/private-corpus" --output "knowledge" --workers 8 --date 2026-10-10
```

日期表示该批次发布日期；默认使用运行当天日期，也可指定 --date。页边、复杂表格、数学式、段落换行和字体异常仍可能留下噪声，故统计不能替代定向核读和语言评价。
