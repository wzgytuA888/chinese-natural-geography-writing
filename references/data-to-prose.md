# 从数据到可核验的分析文字

用于用户给出表格、模型输出或图像，要求撰写结果与分析。先读本文件，再按内容加载句法或模型专题。数据只需支持本次任务；不要因缺少完整论文而停下已能完成的结果写作。

## 1. 建立最小证据台账

记录：事实编号、来源（表名/列名/图/用户陈述）、指标定义与单位、时间、空间单元与尺度、观测/估算/情景类型、比较基准、统计量及检验是否提供。原始事实与计算所得事实分列。

| 已有输入 | 可以写 | 暂不能写 |
|---|---|---|
| 两个年份的量值 | 期末较期初增加/减少及幅度 | 持续增长、波动、转折、趋势显著 |
| 三期及以上完整有序数据 | 这些观测时点上的升降与阶段变化 | 未观测年份的连续过程、统计突变 |
| 分区平均值 | 分区均值排序与差值 | 区内高值斑块、空间集聚、梯度连续性 |
| 一幅地图 | 空间位置、分布形态；可读图值须注明精度 | 数值精确变化、Moran's I、热点显著性 |
| 相关系数和检验 | 给定样本和尺度上的相关方向/强度 | 过程因果、相互促进、必然共增 |
| 情景结果 | 给定假设下的估算与同基准对比 | 历史事实、确定未来、政策真实效果 |

未知项先列在内部台账中。可独立完成的正文正常写；仅将影响当前判断的缺项简短告知用户。不要在交付正文中塞入大量占位符。

## 2. 数值核算先于修辞

- 绝对变化 = 期末值 − 期初值；相对变化 = 绝对变化 / 期初值 × 100%。必须标明基准；基准为零时相对变化无定义。
- 比例由 20% 变为 25%：提高 5 个百分点，相对增幅 25%。无量纲 0—1 指数由 0.20 变为 0.25：增加 0.05，不能未经定义称为提高 5 个百分点。
- 面积占比区分研究区总面积、某地类原面积、全部转出面积和转移总量。某地类转出最多与转出率最高是不同判断。
- 同一单位下总量与单位面积强度分别比较；跨服务不能把 t、m³、无量纲指数直接相加或按原始量值排名。
- 净变化由转入减转出得到；某地类转入、转出之和应称为该地类相关转移面积合计，不能含混称整个研究区的总转移量，也不能当作净损失。
- 归因份额可有负值或超过 100%，应交代分母、抵消项和残差。不得为凑成 100% 擅自归一化。
- 浓度/氮输出量下降与净化服务增强的对应关系取决于指标定义；增加的值未必代表改善。
- 仅有两端点不能计算逐年趋势。年均线性变化与复合增长率也不同；未经用户需要，无须补算多余指标。
- 有样本量也不等于有显著性检验；误差条重叠与否不能自动替代已定义的统计检验。

可用 [../scripts/build_evidence_ledger.py](../scripts/build_evidence_ledger.py) 对已明确、同单位的有序序列核算。该脚本处理量值和基准，不自动读取任意工作簿或证明文字结论。

## 3. 用证据选中心判断

先找最能回应研究问题的变化、对比或反常现象，再决定段落。信息排序通常是：中心发现 → 代表性数值 → 对照/分解 → 例外/范围。证据少时两句即足够；不要为补齐骨架制造空间位置、服务关系或归因。

| 问题 | 段落中心 | 值得保留的对照 |
|---|---|---|
| 服务量如何变化 | 总量及主要时点差异 | 单位面积强度或异向服务 |
| 区域有何差异 | 高低分区或排序 | 总量/强度的不同排序 |
| 存在哪类关系 | 明确指标、样本维度和相关方向 | 不显著单元或尺度反转 |
| 哪个情景更合适 | 按明确目标比较 | 某服务改善而另一服务损失 |
| 模型因素怎么解释 | 对应模型量度的排序或路径 | 方向未知、尺度依赖、替代解释 |

## 4. 先写结果，再决定能否讨论

结果段报告已有估算、比较及模型中的检验关系。用户要求“结果与分析”时，可写数据内的结构分析（增减构成、分区差异、异常）；只有有依据时才补充机制。结果中可说明公式或模型内已检验的关系，不能把未检验的现实解释写成事实。

讨论按“本文发现 → 可比文献/过程证据 → 中间路径 → 替代解释/尺度条件 → 意义”组织。未提供可核验文献时，可以完成基于本文数据的解释并标明推测；不得补造作者年份或引用编号。引言的“研究空白”同样必须经过文献支持。

## 5. 逐句回查

每个数值对应一个事实编号；每个方向词能由这些事实推出；每个“显著、阈值、集聚、驱动、导致”有对应检验或过程证据。然后检查分母、单位、时间顺序、模型本义和例外是否保留。最后处理节奏与用词。

台账和核对过程用于内部工作，默认交付自然成段的论文正文。用户需要审计时，另附“句子—事实编号—推断级别”表。
