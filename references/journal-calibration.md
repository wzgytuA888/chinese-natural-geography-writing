# 对齐《地理学报》与《生态学报》的分析表达

用户只指定期刊时，采用两刊共同标准：明确对象、指标和比较维度，用数值支撑中心发现，保留异常和限定。提供范文时优先对齐相同研究问题与论文部分，不把引言句式迁入结果。

本批两刊各 50 篇，但对象、方法、年份和文章类型分布不同。不能把样本差异断言为刊物固定风格，或声称某刊要求特定句长、词频或结论条数。正式排版与摘要字数须另核验目标期刊当前指南。

## 校准步骤

1. 选择同部分、同类指标、相近方法的少量文章；先读段落功能，再看语言。
2. 标记限定、判断、证据、比较、解释、边界、意义；只迁移功能顺序，不搬原句或真实结论。
3. 对齐全区与分区、总量与强度、空间关系与跨年变化、综合指标与单项服务等比较层次。
4. 调整指代、句子主干和衔接，保留术语精度和条件；不按句长中位数凑字。
5. 检查是否遗漏与主结论不同的区域、服务或情景。限定和例外比宏大意义句更能提高分析精度。

## 按问题检索，两刊均可采用

| 研究重心 | 组织方式 | 语料 |

| 尺度与空间关系 | 判断 → 分异 → 尺度/类型反转 → 条件解释 | p017、p038、p083、p093 |
| 服务与方法比较 | 定义 → 量值 → 分解 → 参数/过程解释 | p006、p054、p059、p078 |
