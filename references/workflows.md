# 分部分写作工作流

## 摘要

采用“问题—数据与方法—核心结果—结论与意义”结构。结果应占主体，优先写方向、空间差异、阈值和机制；不要展开文献综述。

## 引言

先提炼中心科学问题，再组织文献。文献应按主题、尺度或机制分组，每段从“已知什么”推进到“尚不知道什么”。末段交代研究问题、数据方法和贡献，不提前写结果。

## 方法

每种方法至少说明用途、选择理由、关键变量或参数和输出指标。通用公式不必过度解释，但自定义指标必须说明地理意义。数据预处理需支持复现。

## 结果

按已有信息组织中心发现、代表性证据和对照/例外。可报告公式关系、数据构成或已检验模型关联；未检验的现实机制放入讨论并限定证据。缺少空间、类型或驱动信息时不补齐固定顺序。先读 [data-to-prose.md](data-to-prose.md)。

## 讨论

围绕最重要的 2—4 项发现展开，每项使用“发现—文献比较—机制—边界—意义”单元。机制解释优先连接本文结果；外部文献用于佐证，不能替代本文证据。局限必须附带对应改进路径。

## 结论

逐一回应研究问题。不重复方法细节，不写讨论中未出现的新概念。建议需与空间分区、对象类型、阈值或情景相匹配。

## 润色与重写

1. 核对事实、数值、术语与引文编号。
2. 标记每句功能：背景、证据、判断、解释、限定或意义。
3. 删除重复句，补足逻辑桥。
4. 校准因果强度和不确定性。
5. 统一概念、尺度、时态和句式。
6. 最后处理节奏、标点和词汇。

若证据不足，不得靠语言升级把“相关”包装为“机制”；应改为克制表述，或提示作者补充检验。

## 多模型研究

1. 画出数据与模型依赖链，标明每一级输入、输出和验证数据。
2. 区分率定、内部验证、外部验证和尺度聚合验证。
3. 先报告最上游数据或模型的可靠性，再进入下游结果。
4. 对最终结论追溯误差来源，说明哪些偏差可能累积或放大。

## 驱动与机制研究

1. 先确认模型回答的是相关、解释力、重要性、路径、溢出还是因果效应。
2. 分别报告方向、强度、显著性、空间差异和阶段变化，不用一个“影响”概括全部结果。
3. 机制解释至少补充一个中介过程，并说明证据是直接观测、模型支持还是文献推断。
4. 将替代解释、尺度限制和遗漏变量写入讨论，而非藏在结尾套话中。

## 生态系统服务评估（InVEST 类）

1. 需求界定：说明评估哪几类服务、服务与地类/参数如何对应。
2. 数据与模型：交代土地利用数据来源与精度、碳密度/根系深度等参数来源。
3. 精度与边界：报告参数敏感性与边界效应，说明模型为估算而非观测。
4. 结果：先总体格局，再高/低值区，再服务量排序，最后与地类变化对应。
5. 讨论：把服务变化接到过程链上，并限定在给定参数与尺度。

## 情景模拟与预测

1. 情景设定：每个情景给出政策或趋势依据，列情景设置表与转移成本/约束矩阵。
2. 模型链：先数量约束，再空间模拟，最后服务评估；各级单独验证。
3. 精度前置：训练期—预测期—验证年与总体精度、Kappa 独立成段。
4. 结果：历史演变与多情景预测分列；情景对比统一“较……情景，……”。
5. 结论：按研究目标比较情景优势与代价，保留假设条件；没有综合权重时只报告分目标优劣。

## 权衡/协同与供需

1. 先评估各服务的时空格局。
2. 用相关系数、约束线、袋状图等方法识别两两关系，报告方向与强度。
3. 仅在有局地分类与面积数据时报告占比和空间分布；保留不显著与兼容关系，区分空间对应与时间共增。
4. 检验关系是否随尺度、阶段变化，把差异写成条件依赖。
5. 供需型补上匹配类型（盈余/赤字/错位）与流动路径。

## 耦合协调研究

1. 先界定两个系统的内涵与双向作用。
2. 分别测度综合水平，再算耦合协调度并分级。
3. 叠加滞后型/受阻型/同步型亚类判定方向。
4. 用障碍度、贡献度或灰色关联识别主导因素。
5. 讨论区分“高耦合”与“良性协调”，避免误读。

## 归因分解

1. 明确分解框架（气候 vs 人类/下垫面，或自然 vs 社会经济）。
2. 给出方法依据与公式，说明各法回答的问题。
3. 报告贡献百分比，并尽可能用两种方法互证。
4. 把高贡献因子接到中介过程。
5. 写明遗漏变量与模型结构对份额的影响，不写成客观真实贡献率。

## 综述与概念辨析

1. 按维度切块（脉络—框架—方法—机制—调控），不逐篇罗列。
2. 用“由……转向……”“从……拓展到……”概括趋势。
3. 概念按“内涵—外延—测度”界定，并给出相近概念的判据。
4. 展望分层：内容、方法、尺度、政策，每条含对象、路径与目的。
